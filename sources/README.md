# Original sources

Keep originals in the existing local or synced Knowledge folder where they can be opened independently. Configure that parent folder as `KNOWLEDGE_SOURCE_ROOT`; do not move originals into this repository. Locators are category-relative, such as `Transcripts/episode.md`, `Books/title.md`, and `Notes/idea.md`. Keep the root alias and each relative path stable for a stable document ID.

`sources/fixtures/` contains only short synthetic test inputs. Local snapshots and parsed previews go under the ignored runtime directory.
